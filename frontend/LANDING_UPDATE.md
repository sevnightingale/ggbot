# ggbots Landing Page Redesign - Personal Story Edition

## Overview
Transform the current corporate landing page into a personal, indie hacker-style story-driven experience that follows Sev's journey from manual trading to building AI agents. Inspired by levels.io and marc louvion's authentic, personality-driven approach.

## Core Narrative Arc
**"From Basic Bots to AI Agents: A Trader's Journey to Building the Future"**

The landing page tells Sev's story chronologically, building credibility and relatability while demonstrating the problem and solution organically.

## Design System Updates

### Visual Style
- **More Personal:** Photos of Sev, development setup, real screenshots
- **Asymmetric Layouts:** Breaking the grid intentionally for visual interest
- **Diagonal Sections:** Creating visual momentum and breaking corporate feel
- **Progress Indicators:** Live development status, timeline elements
- **Authentic Colors:** Keep the brutalist foundation but add more personality

### Typography
- **Lowercase Priority:** Most text in lowercase for indie feel
- **Personal Tone:** "I built this" vs "we built this"
- **Raw Language:** "money printer", "brutal losses", "completely changed"
- **Technical Accuracy:** Specific details (90% accuracy, 2020 start date)

### Interactive Elements
- **Hover Effects:** Subtle but engaging
- **Progress Bars:** Development status, waitlist position
- **Live Data:** If available (commit activity, etc.)
- **Smooth Scrolling:** Story progression feels natural
